# Fairbeam 0.8.6-preview.4 (macOS preview)

This is a **macOS preview** for HF work. It is a GitHub prerelease, not the Latest release: installed
apps are not offered it and the update feed stays on 0.8.5. Only a signed and notarized Apple silicon
DMG is provided; there is no Windows build of this preview.

## What to test

- **Units per design.** A design now saves its own units, picked under `mm · GHz` in the status bar
  or in the design's Properties ("Units shown and typed"). Settings sets the default for new designs
  and for designs without units of their own. Values are still saved in mm and GHz.
  [#406](https://github.com/ismailakdag/fairbeam/pull/406)
- **Charts in your units.** Frequency axes, their marker labels and frequency readouts in the
  results follow the chosen unit, for example `Frequency (MHz)` and `7.100 MHz`.
  [#406](https://github.com/ismailakdag/fairbeam/pull/406)
- **Energy plot.** The field-energy chart no longer closes into a polygon when a job runs the solver
  more than once, as in a parameter sweep or an optimization.
  [#405](https://github.com/ismailakdag/fairbeam/pull/405)
- Also new since 0.8.6-preview.3: editable antenna designs and explicit NEC wire models from the
  antenna calculator ([#400](https://github.com/ismailakdag/fairbeam/pull/400),
  [#403](https://github.com/ismailakdag/fairbeam/pull/403)), reusable simulation and optimizer
  settings ([#399](https://github.com/ismailakdag/fairbeam/pull/399)), and an opt-in native
  excitation cutoff fix ([#402](https://github.com/ismailakdag/fairbeam/pull/402)).

Everything in [0.8.6-preview.3](0.8.6-preview.3.md) is included: picking units, typed units such as
`1 cm` or `7.1 MHz`, and the HF dipole examples.

## Numerical status of HF examples

The HF dipoles run to their energy stopping criterion and produce complete, finite S11 results.
This shows that the HF path executes; it is **not** a numerical validation. A comparison against
an independent solver has not yet converged, so these results must not be treated as accurate.
The strip stands in for a wire; no mesh convergence is claimed, and S11 alone says nothing about
radiation efficiency or patterns.

## Installing and returning to stable

The preview replaces the installed Fairbeam: it has the same app name, bundle ID, settings,
workspace and managed runtime as the stable release, so it is not a side-by-side install. On its
first start it refreshes the Fairbeam package in the managed runtime.

To return to stable, install the 0.8.5 DMG from the
[0.8.5 release](https://github.com/ismailakdag/fairbeam-releases/releases/tag/v0.8.5). The updater
does not downgrade, so this step is manual. On start, 0.8.5 detects the different package version
and refreshes the managed runtime again.

Requirements: Apple silicon and macOS 27 or later. The app bundle declares macOS 13, but the
managed openEMS runtime pack requires macOS 27.
