# Fairbeam 0.8.6

Fairbeam 0.8.6 lets you pick the units you work in, adds HF examples and an MCP server for AI
assistants, and brings the antenna calculator, NEC2++ wire solves and several designer fixes.
These notes describe the source changes since v0.8.5. The macOS previews 0.8.6-preview.1 to
preview.4 led up to this release; their changes are included.

## Units and HF work

- Pick the units values are shown and typed in: lengths in mm, cm, m, in or mil, frequencies in
  kHz, MHz or GHz. Click `mm · GHz` in the designer's status bar, or use the design's Properties.
  Each design saves its own choice; Settings holds the default for new designs. A number may also
  carry its unit (`1 cm`, `7.1 MHz`). Designs are still stored in mm and GHz, so older projects
  open unchanged, and expressions use the stored values.
  [#393](https://github.com/ismailakdag/fairbeam/pull/393), [#395](https://github.com/ismailakdag/fairbeam/pull/395), [#406](https://github.com/ismailakdag/fairbeam/pull/406)
- Frequency axes, marker labels and frequency readouts of the results follow the chosen unit. Unit
  labels, the 3D scale bar, cursor coordinates and measurements do too. [#395](https://github.com/ismailakdag/fairbeam/pull/395), [#406](https://github.com/ismailakdag/fairbeam/pull/406)
- Designer bands accept HF frequencies (for example `f0 = 0.05` GHz, or a 2–50 MHz band).
  Positive, ordered bands are still required. [#383](https://github.com/ismailakdag/fairbeam/pull/383)
- New HF examples: center-fed strip dipoles at 7.1 MHz (40 m) and 14.2 MHz (20 m), with automatic
  mesh, in a new HF group. Example bands below 0.1 GHz are listed in MHz. Technical drawings gain
  scales down to 1:1000. [#392](https://github.com/ismailakdag/fairbeam/pull/392)
- **Numerical status:** the HF examples run to their energy criterion and give complete S11
  results. A comparison against an independent solver has not converged yet, so they are not
  accuracy-qualified.

## AI assistants (MCP)

- `fairbeam mcp` serves Fairbeam's tools to Claude Desktop, Claude Code and other MCP clients.
  An assistant can list, read, create and edit designs, check them, run simulations, follow and
  cancel runs, sweep parameters, read result summaries (minimum S11, −10 dB bands, Zin, VSWR,
  gain, efficiency) and export Touchstone. It uses the open app's run server, so runs show in the
  app. Settings › AI assistants (MCP) shows the configuration to copy. See docs/MCP.md.
  [#408](https://github.com/ismailakdag/fairbeam/pull/408)

## Designer, calculator and wire models

- Offline antenna starting dimensions on the Start screen; create editable designs from the
  calculator's estimates. [#368](https://github.com/ismailakdag/fairbeam/pull/368), [#400](https://github.com/ismailakdag/fairbeam/pull/400)
- Optional NEC2++ wire solves and dipole matching optimization; import, edit and export explicit
  NEC wire models from the calculator. [#367](https://github.com/ismailakdag/fairbeam/pull/367), [#403](https://github.com/ismailakdag/fairbeam/pull/403)
- A new design whose name is in use gets the next free file name instead of an error. [#392](https://github.com/ismailakdag/fairbeam/pull/392)
- Boolean operations keep operand shape labels, including while editing. [#366](https://github.com/ismailakdag/fairbeam/pull/366), [#386](https://github.com/ismailakdag/fairbeam/pull/386)
- Reusable simulation and optimizer settings are preserved. [#399](https://github.com/ismailakdag/fairbeam/pull/399)
- The field-energy chart no longer closes into a polygon when a job runs the solver more than
  once (sweeps, optimizations). [#405](https://github.com/ismailakdag/fairbeam/pull/405)
- The MIMO diversity table is paged and keeps the selected port pair. [#388](https://github.com/ismailakdag/fairbeam/pull/388)

## Release scope and remaining qualification

- macOS needs Apple silicon and macOS 27 or later (the managed openEMS runtime pack requires it;
  the app bundle declares macOS 13). Windows needs Windows 10 or 11 on x64.
- Simulation results are openEMS FDTD results. Mesh convergence and boundary distance decide how
  far they can be trusted; the HF examples are not accuracy-qualified (see above).
- Windows has updater signatures but no Authenticode publisher signing; see the Smart App Control
  note in WINDOWS.md.
